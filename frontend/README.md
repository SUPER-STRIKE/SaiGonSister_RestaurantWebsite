# SaiGonSister Vietnamese Kitchen

## Run

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

Open `http://localhost:3000`.

Set `NEXT_PUBLIC_API_URL` to the backend (default `http://localhost:4000`).

## Build

```powershell
npm run build
```
